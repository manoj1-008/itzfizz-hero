# 🚗 ITZFIZZ – Scroll Driven Hero Animation

This project is a scroll-based hero section animation built as part of a Web Development Internship assignment for Itzfizz Digital.

The goal was to recreate a smooth, premium scroll experience similar to the given reference demo while maintaining clean structure and performance.

## 🎯 Project Objective

The assignment required:

- A hero section above the fold
- Letter-spaced headline display
- Animated statistics
- Scroll-driven object movement
- Smooth, performant animation using GSAP
- Clean and structured code

This project fulfills all core requirements while keeping the UI modern and responsive.

## ✨ Features

- Scroll-based car movement synchronized with scroll progress
- Pinned hero section using GSAP ScrollTrigger
- Smooth fade and transform animations
- Staggered statistic reveal
- Tech-inspired gradient background
- Responsive layout
- Performance-focused animations (using transform properties)

## ⚙️ How It Works

The animation is controlled using GSAP Timeline and ScrollTrigger:

- The hero section is pinned during scroll.
- Scroll progress drives the animation (scrub enabled).
- The car moves horizontally based on scroll position.
- Text and statistics appear smoothly during movement.
- All animations use transform and opacity for better performance.

This ensures smooth and fluid interaction without heavy scroll event calculations.
